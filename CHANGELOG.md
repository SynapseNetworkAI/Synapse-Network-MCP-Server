# Changelog

All notable changes to Synapse Network MCP Server will be documented in this file.

## 0.1.0 - 2026-04-30

- Added the initial stateless MCP stdio server for SynapseNetwork.
- Exposed `discover_services`, `invoke_and_pay`, and `get_receipt` tools.
- Added direct Gateway HTTP calls with native `fetch` and no Synapse SDK dependency.
- Added mock and live MCP E2E verification scripts.
- Added CI and lightweight source quality gates.
- Added `llms.txt`, `llm-instructions.md`, and MCP Registry metadata.
