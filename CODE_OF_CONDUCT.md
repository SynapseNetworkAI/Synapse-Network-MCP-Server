# Code Of Conduct

We want Synapse Network MCP Server to be a welcoming project for developers and agents building payment-enabled software.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while still being precise about risks.
- Keep discussions focused on the code, docs, security, and user experience.
- Help newcomers understand MCP, Agent Keys, and safe agent payment workflows.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Sharing private keys, seed phrases, tokens, or credentials.
- Pressuring contributors to expose owner, provider, admin, deposit, withdrawal, or settlement capabilities in this MCP server.
- Publishing exploit details or secret material in public issues.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation when behavior makes the project unsafe or unproductive. Security-sensitive material should be redirected to the process in `SECURITY.md`.
